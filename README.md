| File | Owner | What |
|---|---|---|

| `STATE.md` | the agent | Review cursor, open threads, design notes, our branches and their status |
| `SETUP.md` | shared | What the cloud sandbox can and can't do |
| `nightly/YYYY-MM-DD.md` | the agent | One log per night |
